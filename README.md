# FLIQ Digital Flagship

FLIQ Premium Streetwear Digital Flagship Store built with Next.js 15 (App Router), TypeScript, Tailwind CSS v4, Motion, and React Three Fiber.

## Quick Start

```bash
# Install dependencies
pnpm install

# Run development server
pnpm dev

# Run build
pnpm build

# Run linting
pnpm lint

# Run type check
pnpm type-check

# Run format check
pnpm format:check
```
